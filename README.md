## 景気後退シグナル V2

景気後退リスクは、

**CI先行指数による先行警戒**

と

**実体経済指標による現在の悪化確認**

を組み合わせて判定しています。

単一の指標だけで景気後退を判断せず、複数の指標を組み合わせることを重視しています。

## Backtest

過去の景気の山に対する検証では、CI先行警戒について以下の結果が得られています。

- 🟡 注意以上: 5 / 6
- 🟠 警戒以上: 5 / 6
- 🔴 強い警戒: 3 / 6

ただし、空振りも多く確認されているため、現時点では高精度な景気後退予測モデルとは位置づけていません。

## Important Limitations

現在のバックテストには、以下の重要な制約があります。

- 改定後の経済統計を使用している
- 当時の速報値・確報値を完全には再現していない
- 統計の公表ラグを完全には反映していない
- Vintage Data / Real-time Data を使った検証は今後の課題

そのため、バックテスト結果は参考値として扱っています。

## Purpose

このプロジェクトは、

- 日本経済の状態を継続的に把握する
- 指標ごとの変化を数値化する
- 景気悪化の兆候を早期に確認する
- 経済分析の透明性を高める

ことを目的としています。
